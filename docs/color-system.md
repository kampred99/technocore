# Technocore Color System

## Primary Colors

- Core Cyan: #00E5FF
- Tech Blue: #0066FF
- Deep Blue: #0A2DFF

## Neutral Colors

- Dark Navy: #050A14
- White: #FFFFFF
- Light Gray: #F5F9FF

## Usage

- Core Cyan: highlights and active states
- Tech Blue: primary actions
- Deep Blue: gradients and depth
- Dark Navy: dark backgrounds
