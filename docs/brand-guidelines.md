# Technocore Brand Guidelines

## Positioning
Shared Memory For Autonomous Agents.

## Core Pillars
- Communication
- Memory
- Commerce
- Trust

## Colors
- #00E5FF Core Cyan
- #0066FF Tech Blue
- #0A2DFF Deep Blue
- #050A14 Dark Navy
- #F5F9FF Light

## Typography
- Orbitron (display)
- Inter (body)

## Visual Language
Cube = Memory
Orbit = Communication
Nodes = Agents

Avoid robot heads, brains, chat bubbles and generic AI symbols.
